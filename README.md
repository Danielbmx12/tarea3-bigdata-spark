Tarea 3: Procesamiento de Datos con Apache Spark

Descripción del proyecto

Este proyecto desarrolla el procesamiento y análisis de datos utilizando Apache Spark, a partir del conjunto de datos Sample - Superstore.csv.

Objetivo

Procesar y analizar las ventas por categoría de productos y región, utilizando PySpark para obtener resultados que faciliten la interpretación de los datos.

Herramientas utilizadas

Apache Spark

PySpark

Python

Git y GitHub

Archivos del proyecto

Sample - Superstore.csv: conjunto de datos utilizado.

superstore_batch.py: script de procesamiento por lotes.

graficas_superstore.py: script para generar gráficas.

graficas/: visualizaciones de ventas por categoría y región.

resultados_categoria/: resultados del análisis por categoría.

resultados_region/: resultados del análisis por región.

Resultados

Se generaron archivos de resultados y gráficas para analizar el comportamiento de las ventas según la categoría de productos y la región.
